# 以網站特徵與 L2 正則化邏輯斯迴歸辨識釣魚網站

組員：待補

釣魚網站可能偽裝成合法服務，誘使使用者提供帳號密碼與個人資訊。本研究擬利用網站特徵建立二元分類模型，以降低釣魚網站漏判風險，同時評估合法網站遭誤報的情形。研究採用 UCI Phishing Websites 資料集，原始資料包含 11,055 筆紀錄與 30 項已編碼特徵，涵蓋網址、網頁資源、HTML/JavaScript 與網域資訊；原始釣魚及合法資料分別為 4,898 與 6,157 筆。

目前已核對 CSV 與原始 ARFF 的特徵一致性，確認 CSV 將釣魚標籤由 -1 改為 0，合法標籤維持 1，且未發現缺失值。資料另含大量重複特徵組合，其中 64 組具有不同標籤。因此，本研究擬依相同特徵組合分組切分資料，避免相同輸入出現在訓練與評估資料，並以唯一列版本進行敏感度分析。

模型擬採用 z=wᵀx+b 與 sigmoid 函數的邏輯斯迴歸，保留 30 項輸入特徵，以二元交叉熵及 L2 正則化訓練。程式內將釣魚定義為正類，初始決策閾值為 0.5。資料依特徵組合分組切分為約 80% 訓練集、10% 驗證集與 10% 測試集；在訓練集內進行五折分層分組交叉驗證，評估標準化與未縮放方案，並以獨立驗證集確認所選設定；標準化統計量僅由每折訓練資料估計。學習率、正則化強度等設定尚待決定。

參考既有釣魚辨識模型比較研究，本研究將與多數類別基準模型比較，報告混淆矩陣、釣魚召回率、精確率、F1 與誤報率。預期貢獻為建立可重現且具可解釋性的分類流程，並釐清重複資料與評估方式對結果的影響。目前尚未完成模型訓練，實驗成效將於後續驗證；歷史特徵資料的結果亦不代表對現今未知網站的直接防護能力。

關鍵字：釣魚網站、邏輯斯迴歸、L2 正則化、交叉驗證、資料洩漏

資料來源：https://archive.ics.uci.edu/dataset/327/phishing%2Bwebsites
