# 資料來源與授權

UCI Phishing Websites，11,055 筆、30 個特徵。資料授權：CC BY 4.0。

來源：https://archive.ics.uci.edu/dataset/327/phishing+websites

引用：Mohammad, R. & McCluskey, L. (2012). Phishing Websites [Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C51W2X

`raw/Training Dataset.arff` 為提供的原始 ARFF；`phishing_dataset.csv` 為組員提供的轉換版本。ARFF 的 Result=-1（釣魚）轉為 CSV 的 0；合法網站保留 1。訓練程式再將釣魚映射為正類 1。

報告原列 DOI 與現行 UCI 頁面不同；本文件採現行 UCI 引用資訊，原報告保留原貌。
